#Definitions

Impacted Documentation is a Word document attached to the CC that lists every document, file, or drawing created, revised, or otherwise affected by the change. It is a flat table with seven columns: Document Identifier, Current, As Found, As Attempted, As Left, New Revision, Initial/Date. Only the Document Identifier column is filled in when preparing the document — all other columns are filled manually during the CC process in ePDM.

Document names must be listed exactly as they appear in the document management system. No paraphrasing. Common file types include .ACD files for PLC programs, .docx for design documents, .pdf and .dwg for drawings, and recipe names without extensions. There are no section headers or sub-headers — it is a flat list.

To write it you need: the exact file and document names as they appear in ePDM or ETQ.

> [!info]- Examples
>
> Drawing files (PDF and DWG listed as separate rows):
> 5000LTanks_TK_1010_Mechanical_D10953.pdf
> 5000LTanks_TK_1010_Mechanical_D10953.dwg
>
> PLC program file:
> PCS_PLC_LargeScale.ACD
>
> Recipe name (no extension):
> MC127_1200L
