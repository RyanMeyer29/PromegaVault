#Definitions

The Additional Description is the expanded narrative explaining the change in full detail. There is no character limit. It lives in the Initiation & Planning stage alongside the Brief Description.

The structure should follow: current state, the problem or need if applicable, then what is being done. Plain text, active voice. It can reference specific document names, equipment tags, SAP numbers, and file names. Simple changes can be one or two sentences if the Brief Description already covers most of it. For multi-scope CCs, label each sub-change and describe it separately.

To write it you need: current state and background context, the specific scope of what is changing, and any relevant technical details.

> [!info]- Examples
>
> Single-scope, moderate length — equipment removal:
> The vent filters installed on Feynman bulk production tanks will be permanently removed and the openings capped. This change includes updates to remove the filter from the bulk production tank P&IDs and from SAP inventory. Fill IBC unit procedures for all relevant production recipes will be revised to ensure the tank vent valve is open during applicable steps. Production recipes for each tank size will be tested post-modification to verify proper venting.
>
> Single-scope, minimal:
> Adding a new caustic wash step to the Media Prep CIP as well as all related steps necessary to support the additional caustic wash. Adding this process step will also involve modifying recipe parameters.
>
> Multi-scope — each sub-change labeled separately:
> For a dual-scope change, open with one sentence describing the overall purpose, then add a labeled paragraph per sub-change describing what is being modified, what logic or hardware is affected, and what is explicitly not changing.
