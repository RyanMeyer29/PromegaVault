## 6.1 General

Geometric characteristic symbols are the primary means of specifying geometric tolerances. Where the meaning of a symbol is not clear, a note may supplement the symbol.

## 6.2 Use of Notes to Supplement Symbols

Notes used with symbols shall be placed adjacent to the feature control frame or as a separate note with a leader pointing to the feature control frame.

## 6.3 Symbol Construction

Key symbols used on drawings:

**Geometric Characteristic Symbols** (Figure 6-1, PDF p.72):
- Form: Straightness —, Flatness ⬡, Circularity ○, Cylindricity ⌭
- Profile: Profile of a Line ⌒, Profile of a Surface ⌓
- Orientation: Angularity ∠, Perpendicularity ⊥, Parallelism //
- Location: Position ⊕, Concentricity (removed in 2018), Symmetry (removed in 2018)
- Runout: Circular Runout ↗, Total Runout ⇗

Note: Concentricity and symmetry symbols were REMOVED in ASME Y14.5-2018. Position or profile tolerances should be used instead for coaxial and symmetrical feature control.

**Modifier Symbols:**
- Maximum Material Condition (MMC): M (circled)
- Least Material Condition (LMC): L (circled)
- Regardless of Feature Size (RFS): S (circled) — rarely used, RFS is the default
- Projected Tolerance Zone: P (circled)
- Free State: F (circled)
- Tangent Plane: T (circled)
- Unequally Disposed Profile: U (circled)
- Translation: ► (right-pointing arrow)
- Dynamic Profile: D (circled)
- Continuous Feature: CF
- Independent: I (circled)

**Other Symbols:**
- Diameter: ⌀
- Spherical Diameter: S⌀
- Radius: R
- Spherical Radius: SR
- Controlled Radius: CR
- Reference: ( ) parentheses
- Arc Length: ⌢ (arc over dimension)
- Basic Dimension: boxed value
- Counterbore/Spotface: ⌴
- Countersink: ∨
- Depth: ▼
- Square: □
- Dimension Origin: ○— (circle at one end of extension line)
- Slope: ▷ (triangle)
- Conical Taper: ▷ (filled)
- All Around: ○ (at bend of leader)
- All Over: two concentric circles at bend of leader
- Between: ↔

## 6.4 Feature Control Frame Symbols

A feature control frame consists of:
1. Geometric characteristic symbol
2. Tolerance value (preceded by ⌀ if cylindrical zone)
3. Material condition modifier if applicable (M or L)
4. Datum feature references (first, second, third) with modifiers if applicable

Format: [Symbol | Tolerance | Datum A | Datum B | Datum C]

Multiple feature control frames may be combined or stacked.

## 6.5 Feature Control Frame Placement

A feature control frame is associated with a feature by:
(a) Placing it below or adjacent to the dimension for the feature
(b) Running a leader from the frame to the feature surface
(c) Attaching to an extension line from the surface
(d) Placing it below a note pertaining to the feature

## 6.6 Tolerance Zone Shape

Where the tolerance value in a feature control frame is preceded by ⌀, the tolerance zone is cylindrical. Without ⌀, the tolerance zone is defined by two parallel planes or boundaries.

## 6.7 Tabulated Tolerances

Where many identical features require different tolerance values, tolerances may be tabulated. A letter (or letters) in the feature control frame identifies the feature, and tolerance values are given in a table on the drawing.
