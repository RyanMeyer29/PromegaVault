# AppA - Principal Changes - ASME Y14.5-2018

**Standard:** ASME Y14.5-2018 Dimensioning and Tolerancing
**Appendix:** Appendix A (Nonmandatory)
**PDF pages:** 328-332

## Overview

Appendix A summarizes the principal changes and improvements from ASME Y14.5-2009 to ASME Y14.5-2018. Useful for understanding what changed and why.

## Key Changes from 2009 to 2018

**A-1 Reorganization** — Material formerly in Section 1 was reorganized into Sections 1 through 4, with subsequent sections renumbered.

**A-2 Model-Based Definition** — Model views added to many example figures to ensure the standard applies to dimensions and tolerances in 3D models, not just 2D drawings.

**A-3 Profile for Location** — Emphasis shifted toward using profile tolerances for location of surfaces rather than direct plus/minus limit dimensions. Plus/minus location tolerancing moved to Appendix I and flagged for likely removal in future revision.

**A-4 Concentricity and Symmetry Removed** — The concentricity and symmetry symbols were eliminated. These are now controlled using position or profile tolerances, which provide clearer and better-defined requirements.

**A-5 True Geometric Counterpart** — The term "true geometric counterpart" replaced "theoretical datum feature simulator" for clarity. Applicable only to datums.

**A-6 As-Designed Dimension Value** — Explicit statement added: UOS, the as-designed dimension value does not establish a functional or manufacturing target.

**A-7 Section 5 Changes** — Updates to tolerancing and limits, including clarification of Rule #1 applicability, and addition of the dynamic profile modifier.

**A-8 Dynamic Profile Modifier** — New modifier D (circled) added to support profile tolerances that allow scaling/size variation while controlling form.

**A-9 Section 7 Changes** — Enhancements to datum reference frame concepts including customized DRFs, translation modifier, and irregular features of size as datum features.

**A-10 Nonuniform Tolerance Zones** — Expanded coverage of nonuniform tolerance zone boundaries for profile tolerancing.

**A-11 Composite Tolerancing** — Clarifications to composite position and profile tolerancing, including addition of three-segment composite feature control frames.

**A-12 Section 10 Changes** — Updates to positional tolerancing including bidirectional tolerancing, pattern location, and coaxial controls.

**A-13 Section 11 Changes** — Profile of a surface expanded significantly — now the preferred method for locating surfaces. Composite profile and multiple single-segment tolerancing clarified.
