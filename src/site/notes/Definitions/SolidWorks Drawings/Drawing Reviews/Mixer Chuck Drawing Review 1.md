##  Chuck, Mixer, Style A (SAP 1016437) 

- [x] Update equipment numbers in Notes section of title block (top left) — these are style-specific and need to reflect the correct units
- [x] All title block text in ALL CAPS
- [x] Larger sheet format if needed
- [x] Add Note 3: BREAK ALL SHARP EDGES (remove any tiny chamfer dimensions covered by this)
- [x] Add engraving location callout on part for Note 1 (engrave drawing number)
- [x] Consistent chamfer dimensioning style
- [x] All diameters shown on rectangular view, not circular view where possible
- [x] All dimensions measurable in real life — replace radius dims with diameters where center is not physically accessible
- [x] Measure from bottom of circle, not center, for cylinder with flat edge (set screw flat)
- [x] Add tolerances to diameters where necessary — confirmed -0.001 / +0.000 for bearing surfaces
- [x] Update material callout in title block to 316L STAINLESS STEEL (confirmed spec)
- [x] Snap ring grooves — add detail view with dimensions for one groove; dimension one side only in detail view; pull dims from snap ring data sheet. Note: do not assume any shaft diameters are equal — sections 1, 2, 3, and 4 must all be dimensioned independently (see shaft diameter note below)
- [x] Shaft diameter discrepancy confirmed intentional — 1.376 (section 1) is larger by design; sections 2 and 4 are bearing surfaces at 1.374; section 3 is a separate smaller step. All four must be explicitly dimensioned, none can be assumed equal to another
- [x] Tapered inlet — dimension opening diameter, inside diameter, and angle; remove tapered section length (hard to measure)
- [x] Bearing surfaces — add surface finish callout of 24 Ra and tolerance of +0.001 / -0.000
- [x] Hole near threaded area — exists in real life but not in model; measure and add to model
- [x] Update drawing to include hole once modeled
- [ ] Fill out part file properties using macro (SAP#, Equipment#, Description, Material, Finish, DesignedBy, DesignedDate)
- [ ] Confirm title block fields in drawing are linked to part file custom properties

## Questions for Travis (resolved 2026-05-04)

- [x] Chuck shaft diameter: 1.374 vs 1.376 — intentional. Section 1 is 1.376 (larger by design). Sections 2 and 4 are bearing surfaces at 1.374. Section 3 is a separate smaller step. All four must be dimensioned independently.
- [x] Stainless steel grade — 316L SS for all machined parts (chuck bodies, stop, spanner tool stainless components, chuck tool stainless components). Collet cap is manufacturer spec 440C. Collet is stock (see [[Definitions/Parlec ER32 Collet\|Parlec ER32 Collet]]).
- [x] Spanner tool handle — handle follows dimensions of existing plastic handle on hand. Handle is welded in place. Drawing needs full rework as multi-sheet.
- [x] Stop set screw — stop is not tapped. Collet cap is tapped M4 x 0.7. M4 x 0.7 screw threads into cap and clamps stop against it. Stop needs a clearance hole only.
- [x] Snap ring groove — detail view still required. Pull dims from data sheet. Do not assume shaft diameters match — all must be explicitly dimensioned.
